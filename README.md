## 🔨 Currently building

- 🗣️ **Inglesando** — an AI English coach for Brazilian devs: it learns from *your* mistakes and turns them into personalized practice. `Next.js 16 · Prisma · Postgres · Claude/Gemini`
- 🧠 **LifeOS** — a local-first personal organizer and second brain. `TypeScript · Postgres · Docker · Playwright`
- 💼 **Job-search automation** — a Claude Code workflow that evaluates job posts and tailors CVs and cover letters.
- 🎬 **AI Shorts pipeline** — script → narration → video, rendered with Remotion and orchestrated by agents.
